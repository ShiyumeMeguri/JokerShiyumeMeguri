# 小丑竟是我自己

我的愚蠢行为记录。

一条一个文件，按认出的顺序编号，README 只做目录。

不是为了自我羞辱——自我羞辱不花钱，也改不了任何东西。
是为了下次能提前认出来。

**这个仓库是 issue tracker，不是作品集。** 认出 ≠ 修好；一条写完的那天，状态是**未验收**，不是完成。

## 🔴 顶级优先级 · 准入检查

**[001](愚蠢/001-我把账单烧了.md) 是所有条目的准入检查，排在这份清单的一切规则前面。**

**严禁以错误的方式反思。** 这是目前为止最根源的一处错误：判断一条反思有没有效，必须永远看**全局最优**——下次同样的情形出现，行为有没有真的从 C 变成 B；不能看**局部最优**——审视得多频繁、用词多狠、写的时候多痛。CPU 占用率 100% 不等于吞吐量高，也可能是死循环。自我厌恶（宾语是人，例如"我就是这样一个人"）正是把局部最优冒充成全局最优的典型形态：不可证伪，不产生任何行为修订，还会把外部的纠错信号也吸收成燃料，让自己在"审视频率"上打出满分、在"修订产出"上交白卷。

不管是自己写，还是 AI 协助整理，任何一条新反思落笔前都要先做这个跳出局部最优的判断，并过 001 的四道闸——过不了不算一条，也不许用更狠的自我批评去掩盖过不了这件事本身（那正是 001 说的复发）。

| 闸 | 问的问题 | 挡的东西 |
| --- | --- | --- |
| **宾语闸** | 句子的宾语是不是具体行为/判断/时刻？ | 「我是一个 ___ 的人」——语法上就没留出可改的位置 |
| **差异闸** | 有没有以"下次出现 A，我做 B 而不是 C"收尾？ | 「我以后会更注意」——没有 B 和 C |
| **无聊闸** | 读起来像工程 issue 还是像文章？ | 情绪强烈、"写得很好"——文学性在这里是污染物 |
| **风险闸** | 这条有没有让我暴露在可能落空的风险里？ | 「下次多想三秒」——有 B 有 C，但不可能被判为没做到 |

第 2 道挡**形状**，第 4 道挡**含金量**。（原第 4 道是"收款方闸"，已换掉，理由见 001。）

## 愚蠢清单

- [001 · 我把账单烧了，然后以为自己付过了](愚蠢/001-我把账单烧了.md) — 自我厌恶的宾语是人，自省的宾语是行为；以人为宾语的批评在语法上就无法产生修订。它不只是无效，它还吸收一切纠错信号。**（准入检查，见上）** · `未验收`

## 分析

不是反思。反思的宾语是行为（我做错了什么，下次怎么改）；分析的宾语是判断本身（我对某件事的看法是什么、它站不站得住）。不走验收流程，但一样要经得起打。

- [001 · 误差信号与开环漂移](分析/001-误差信号与开环漂移.md) — 变强 = 拿到带位置的误差信号 × 运行次数。判别器按层分布不按领域分布；风格是产量的残差不是空间里的位置；**自卑和自信是同一个开环系统的两个偏置符号**。

## 新增条目

正文写进 `愚蠢/`，编号递增，README 加一行 `- [编号 · 标题](路径) — 一句话 · 状态`。

**每条至少要有：**

- **真实因果链** —— 不是感受，是步骤
- **我当时的结论错在哪** —— 具体哪一步跳掉了
- **状态**：`未验收 / 已验收 / 未通过`
- **待验收的差异**：下次出现 A，我做 B 而不是 C
- **验收日期**：认出时间 + 30 天

只有情绪、没有判据的，不算一条。

写之前先过 [001](愚蠢/001-我把账单烧了.md) 的四道闸——这是准入检查，排在这份清单所有规则的前面。

## 验收

到期回来看那个可观测的差异发生了没有。

- 发生了 → 标 `已验收`。
- 没发生 → 标 `未通过`。**然后只做一件事：把差异改小，小到我确定能执行。**
  不许重写、不许加长、不许追加更狠的自我批评——那正是 001 说的复发。

> **一条长期停在"未验收"的条目，是一条伪装成工程文档的自我厌恶。**
> 这是最需要警惕的形态——因为它连格式检查都通过了。
